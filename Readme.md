# Usage

Copy 'avlib-1.vdplugin' to 'VirtualDub2\plugins64' or 'VirtualDub2\plugins32' folder.

Copy FFMpeg 9.0 DLLs to 'VirtualDub2' folder.
* avcodec-63.dll
* avformat-63.dll
* avutil-61.dll
* swresample-7.dll
* swscale-10.dll 

FFMpeg x64 binaries used:
* https://github.com/BtbN/FFmpeg-Builds/releases

FFMpeg win32 binaries used:
* https://github.com/defisym/FFmpeg-Builds-Win32/releases
